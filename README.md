# 콩이의 방 (Kongi's Room) 🐾

> 일할 때, 공부할 때 내 곁에서 함께 시간을 보내는 아늑한 디지털 반려 메이트 & 집중 타이머 PWA

---

## 🌿 프로젝트 개요

'콩이의 방'은 기존의 차갑고 기능적인 생산성 타이머(포레스트, 열품타 등)와 달리,  
**혼자 일하거나 공부할 때 찾아오는 적막함을 채워주는 '바디 더블링(Body Doubling)' 반려 공간**입니다.

브라우저 창 한 켠에 아늑한 방을 열어두면, 귀여운 동물(콩이)이 소파 위에서 자기의 시간을 보내며 쌔근쌔근 쉬고 있습니다.  
타이머를 끝까지 마치면 간식을 줄 수 있고, 완주할 때마다 책상 위에 책이 한 권씩 쌓이며, 콩이가 때때로 선반에 작은 보물을 선물합니다.

---

## ✨ 핵심 컨셉 & 4대 주요 기능

### 1. 벌칙 대신 '귀여운 서운함' & '반가운 기지개' 🐱
- **서운함 연출**: 중간에 멈추면 방 밖으로 매정하게 나가는 대신, 콩이가 소파 구석에서 삐진 척 등을 돌려 웅크립니다 (`힝…` 말풍선). 슬쩍 눌러보면 뒤돌아보며 반응합니다.
- **반가운 기지개**: 다시 타이머를 시작하면 콩이가 등을 휙 돌리고 시원하게 기지개를 켜며 (`야옹!`, 하트) 반갑게 반겨줍니다.

### 2. 날씨 & ASMR 사운드 🌧️
- **창문 빗방울**: 상단 `🌧️ 빗소리` 버튼을 누르면 창문에 빗방울이 사선으로 흘러내리고 유리창에 물방울이 맺힙니다.
- **실시간 사운드**: Web Audio API로 합성된 편안하고 잔잔한 빗소리가 방을 채워 작업 시 집중력을 높여줍니다.
- **스토리 카드 연동**: 비 오는 모드에서 오늘의 방 카드를 만들면 창문에 비가 내리는 감성 카드가 생성됩니다.

### 3. 가변 보상: '콩이의 보물 선반' 🌿
- **작은 선물**: 타이머를 완주하고 간식을 줄 때마다, 콩이가 어디선가 보물을 물어와 벽 선반에 얹어둡니다 (`선물!` 말풍선).
- **수집의 즐거움**: 바스락거리는 단풍잎(🍂), 알록달록 털실(🧶), 통통한 도토리(🌰), 반짝이는 병뚜껑(🔘), 작은 들꽃(🌼), 파랑 깃털(🪶) 등 6종의 보물이 선반에 모입니다.
- **선반 상세 보기**: 방 안의 선반을 클릭하면 콩이가 모아온 보물 목록과 따뜻한 메모를 확인할 수 있습니다.

### 4. 집중 폴라로이드 앨범 📸
- **순간의 기록**: 세션을 완주할 때마다 그 시간의 방 풍경(아침, 낮, 노을, 밤, 비)과 집중 시간이 폴라로이드 사진처럼 기록됩니다.
- **감성 아카이브**: 상단 `📸 집중 앨범` 버튼을 누르면 콩이와 함께 쌓아온 집중의 시간들을 한눈에 넘겨볼 수 있습니다.

## 📂 저장소 구조

```text
├── index.html              # 타이머 앱 본체 (마크업)
├── app.css / app.js        # 스타일과 앱 스크립트
├── robots.txt / sitemap.xml # 검색엔진 안내
├── assets/                 # 방 일러스트(webp), 콩이 스프라이트, 미리보기 그림(og.jpg)
├── manifest.webmanifest    # PWA 매니페스트 (홈 화면 추가, 스탠드얼론 설정)
├── sw.js                   # 오프라인 캐싱 서비스 워커
├── render-icons.js         # 앱 아이콘 렌더링 스크립트
├── icons/                  # PWA 앱 아이콘 (192, 512, maskable, apple-touch, svg)
├── docs/
│   └── ideation.md         # 초기 기획 및 Claude 브레인스토밍 대화 전체 기록
└── README.md               # 프로젝트 안내서
```

## 🚀 로컬 실행 방법

외부 의존성 없는 정적 웹 앱이므로 로컬 서버로 바로 실행할 수 있습니다:

```bash
# Python 내장 웹 서버 실행
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 🔧 카카오톡 공유 켜기 (선택)

공유 시트의 카카오톡 버튼은 기본으로 휴대폰 공유창이나 "복사 후 붙여넣기"로 동작합니다. 카카오 공유 API로 바로 보내려면:

1. https://developers.kakao.com 에서 앱을 만들고 **플랫폼 → Web** 에 `https://anbucare.github.io` 를 등록합니다.
2. 앱 키 중 **JavaScript 키**를 복사해 `app.js` 의 `const KAKAO_JS_KEY=''` 안에 넣습니다.
3. 배포하면 카카오톡 버튼이 카카오 공유창(미리보기 그림 + "나도 해 보기" 버튼)을 엽니다.

## 🌐 도메인 연결 (선택)

도메인을 사면 저장소 **Settings → Pages → Custom domain** 에 입력하고, DNS에 `CNAME anbucare.github.io` 를 추가합니다. 이후 `index.html` 의 canonical·og:url·sitemap.xml 주소를 새 도메인으로 바꾸면 됩니다. GitHub Pages는 예전 `github.io` 주소를 새 도메인으로 자동 301 이동시킵니다.

## 🗺️ robots.txt 참고

프로젝트 사이트라 `robots.txt` 는 `/Kongi-room/robots.txt` 에 있고, 검색엔진이 보는 도메인 루트(`anbucare.github.io/robots.txt`)에는 올라가지 않습니다. 루트에 두려면 `anbucare.github.io` 이름의 저장소를 만들어 그 안에 robots.txt 를 두고 `Sitemap: https://anbucare.github.io/Kongi-room/sitemap.xml` 줄을 적으면 됩니다. 페이지 `<head>` 에는 `<link rel="sitemap">` 으로 사이트맵 위치를 적어 두었습니다.

## 🔗 결과 링크 미리보기 (Cloudflare Worker, 선택)

친구에게 보내는 결과 링크마다 다른 미리보기(제목·설명·그림)를 주려면 `worker/` 폴더의 Cloudflare Worker를 배포합니다. 배포 절차와 두 가지 그림 방식(무료 플랜용 미리 만든 그림 / 유료 플랜용 실시간 그림)은 `worker/README.md` 에 있습니다. 미리 만든 그림 108장은 `assets/og/` 에 들어 있습니다.
