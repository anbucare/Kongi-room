# 콩이의 방 (Kongi's Room) 🐾

> 일할 때, 공부할 때 내 곁에서 함께 시간을 보내는 아늑한 디지털 반려 메이트 & 집중 타이머 PWA

---

## 🌿 프로젝트 개요

'콩이의 방'은 기존의 차갑고 기능적인 생산성 타이머(포레스트, 열품타 등)와 달리,  
**혼자 일하거나 공부할 때 찾아오는 적막함을 채워주는 '바디 더블링(Body Doubling)' 반려 공간**입니다.

브라우저 창 한 켠에 아늑한 방을 열어두면, 귀여운 동물(콩이)이 소파 위에서 자기의 시간을 보내며 쌔근쌔근 쉬고 있습니다.  
타이머를 끝까지 마치면 간식을 줄 수 있고, 완주할 때마다 책상 위에 책이 한 권씩 쌓입니다.

---

## ✨ 핵심 컨셉 & 주요 기능

1. **마지막 2분의 설렘 (기다리는 동물)**
   - 타이머 종료 2분 전이 되면 동물이 잠에서 깨어 기지개를 켜고 빈 밥그릇 앞으로 다가와 화면 쪽을 바라봅니다.
   - 알람 소리의 스트레스 대신 "누군가 나를 기다리고 있는 따뜻한 순간"을 선물합니다.

2. **생생하고 사랑스러운 고양이 움직임**
   - 자기, 뒹굴기, 소파 등받이에 올라가 창밖 바라보기(창밖에 새가 날아감), 러그에서 그루밍 및 기지개.
   - 가만히 있을 때도 숨 쉬기, 눈 깜빡임, 귀 움찔, 꼬리 튕기기, 곁눈질, 하품이 자연스럽게 이어집니다.
   - 간식을 주면 그릇 앞으로 걸어가 사료를 오독오독 먹고(사료 줄어듦), 혀로 입맛을 다신 뒤 앞발로 세수하고 소파로 돌아갑니다.

3. **안전하고 따뜻한 벌칙: '빈 밥그릇'**
   - 일시 정지나 탭 실수로 동물이 영영 밖으로 나가버리는 가혹한 벌칙 대신, 문 앞까지 걸어가 슬쩍 뒤돌아보고 밥그릇이 빈 채로 남습니다. 다음 타이머를 켜면 다시 돌아옵니다.

4. **쉬는 시간 상호작용**
   - 집중 중에는 동물을 건드릴 수 없지만, 완주 후 주어지는 휴식 시간(5분/10분)에는 러그로 나온 콩이를 쓰다듬으며 골골송(하트)을 나눌 수 있습니다.

5. **자연스러운 하루 누적 & 인스타 스토리 카드**
   - 세션을 완료할 때마다 책상 위에 책이 한 권씩 쌓이고(자정에 초기화), 하루 공부가 끝나면 방의 조명과 누적 시간이 담긴 "오늘의 방" 카드를 인스타그램 스토리 비율로 저장할 수 있습니다.

6. **시간대별 방 조명 & PWA 오프라인 지원**
   - 실제 시간대(아침, 낮, 노을, 밤)에 따라 방의 빛이 달라지며 밤에는 따뜻한 스탠드가 켜집니다.
   - PWA(Progressive Web App)를 지원하여 모바일 및 PC 브라우저에서 '홈 화면에 추가'하면 주소창 없는 단독 앱으로 작동하며 오프라인에서도 열립니다.

## 📂 저장소 구조

```text
├── index.html              # 타이머 앱 본체 (HTML/CSS/JS 단일 번들)
├── manifest.webmanifest    # PWA 매니페스트 (홈 화면 추가, 스탠드얼론 설정)
├── sw.js                   # 오프라인 캐싱 서비스 워커
├── render-icons.js         # 앱 아이콘 렌더링 스크립트
├── icons/                  # PWA 앱 아이콘 (192, 512, maskable, apple-touch, svg)
├── docs/
│   └── ideation.md         # 초기 기획 및 Claude 브레인스토밍 대화 전체 기록
└── README.md               # 프로젝트 안내서
```

## 🚀 로컬 실행 방법

외부 의존성 없는 정적 웹 앱이므로 로컬 서버로 바로 실행할 수 있습니다:

```bash
# Python 내장 웹 서버 실행
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.
