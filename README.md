# 콩이의 방 (Kongi's Room) 🐾

> 일할 때, 공부할 때 내 곁에서 함께 시간을 보내는 아늑한 디지털 반려 메이트 & 집중 타이머 PWA

---

## 🌿 프로젝트 개요

'콩이의 방'은 기존의 차갑고 기능적인 생산성 타이머(포레스트, 열품타 등)와 달리,  
**혼자 일하거나 공부할 때 찾아오는 적막함을 채워주는 '바디 더블링(Body Doubling)' 반려 공간**입니다.

브라우저 창 한 켠에 아늑한 방을 열어두면, 귀여운 동물(콩이)이 소파 위에서 자기의 시간을 보내며 쌔근쌔근 쉬고 있습니다.  
타이머를 끝까지 마치면 간식을 줄 수 있고, 완주할 때마다 책상 위에 책이 한 권씩 쌓이며, 콩이가 때때로 선반에 작은 보물을 선물합니다.

## ✨ 핵심 컨셉 & 주요 기능

### 1. 벌칙 대신 '귀여운 서운함' & '반가운 기지개' 🐱
- **서운함 연출**: 중간에 멈추면 방 밖으로 매정하게 나가는 대신, 콩이가 소파 구석에서 삐진 척 등을 돌려 웅크립니다 (`힝…` 말풍선). 슬쩍 눌러보면 뒤돌아보며 반응합니다.
- **반가운 기지개**: 다시 타이머를 시작하면 콩이가 등을 휙 돌리고 시원하게 기지개를 켜며 (`야옹!`, 하트) 반갑게 반겨줍니다.

### 2. 날씨 & ASMR 사운드 🌧️
- **창문 빗방울**: 상단 `🌧️ 빗소리` 버튼을 누르면 창문에 빗방울이 사선으로 흘러내리고 유리창에 물방울이 맺힙니다.
- **실시간 사운드**: Web Audio API로 합성된 편안하고 잔잔한 빗소리가 방을 채워 작업 시 집중력을 높여줍니다.
- **스토리 카드 연동**: 비 오는 모드에서 오늘의 방 카드를 만들면 창문에 비가 내리는 감성 카드가 생성됩니다.

### 3. 가변 보상: '콩이의 보물 도감' (No.001 ~ No.048) 📖
- **집중 시간이 물건이 됩니다**: 간식을 줄 때마다 콩이가 보물을 하나 물어옵니다. 어떤 보물이 나오는지는 완주한 시간에 달려 있습니다.
  - 15분 이상: 산책길의 조각 (반짝이는 도토리, 붉은 단풍잎 …)
  - 25분 이상: 포근한 손길 (폭신한 수제 털실공, 고양이 발바닥 북마크 …)
  - 50분 이상: 깊은 오후의 발견 (미니어처 유리 온실, 앤틱 회중시계 …)
  - 120분 이상: 별이 내려앉은 밤 (콩이의 오르골, 은하수 유리구슬 …)
- **도감**: 방 안의 선반을 클릭하면 48칸 도감이 열립니다. 아직 못 찾은 칸은 `???` 로 표시되고, 몇 분을 완주해야 나오는지 힌트가 보입니다. No.048 황금 방울은 친밀도 Lv.4 가 되면 받습니다.
- **벽 선반**에는 최근에 물어온 보물 6개가 올라갑니다.

### 4. 집중 폴라로이드 앨범 & 에세이 카드 📸
- **순간의 기록**: 세션을 완주할 때마다 그 시간의 방 풍경(아침, 낮, 노을, 밤, 비)과 집중 시간이 폴라로이드 사진처럼 기록됩니다.
- **에세이 카드**: 폴라로이드 화면의 `에세이` 탭을 누르면 같은 기록이 킨포크·아트북 느낌의 4:5 카드로 바뀝니다. 명조체, 넉넉한 여백, `No. 012 포근한 밤의 서재 / Oberursel의 밤, 콩이와 함께한 50분` 형식의 제목과 부제. 장소는 한 번만 입력하면 기억됩니다. 명조 글꼴(Gowun Batang)은 에세이 탭을 열 때만 불러옵니다.
- **감성 아카이브**: 상단 `📸 집중 앨범` 버튼을 누르면 콩이와 함께 쌓아온 집중의 시간들을 한눈에 넘겨볼 수 있습니다.

### 5. '무릎냥이 잠재우기' 모드 🛏️
- 시작 화면의 체크박스를 켜면 타이머 동안 콩이가 방석 위에 자리를 잡고 골골송(저음 진동 + 파동 애니메이션)을 부르며 잠듭니다.
- **화면을 벗어나거나(다른 탭·앱으로 이동) 멈추면** 콩이가 깜짝 놀라 깨서 `!?` 하며 서운한 눈으로 쳐다봅니다. 돌아오면 3초 뒤 다시 눈을 감습니다. 깨운 횟수는 상태 문구와 공유 카드에 남고, 한 번도 깨우지 않고 완주하면 공유 문구가 "콩이가 깰까 봐 폰을 못 만지겠어요🥺"로 바뀝니다.
- 이 모드에서는 2분 전 밥그릇 대기 없이 끝까지 잠들어 있다가 완주 순간에 깨어납니다.

### 6. 4단계 몰입 모션 🐾
- 타이머 진행률에 따라 콩이가 `자리 잡기(0~10%) → 식빵 굽기(10~35%) → 깊은 꿀잠과 골골송 파동(35%~) → 완주 시 기지개 켜며 반가운 눈인사` 로 바뀝니다. 진행 바 아래에 현재 단계가 표시됩니다.
- 일반 모드에서는 식빵 굽기 단계에만 창가·러그·책상으로 잠깐 다녀오고, 꿀잠 단계부터는 소파에서 움직이지 않습니다.

### 7. 내가 머물고 싶은 집중 공간 (픽셀 테마) 🏠
- 상단 `🏠 집중 공간` 버튼으로 방을 고릅니다. 기본 `콩이의 방` 외에 4곳이 있고, 콩이의 자리(잠자리·창가·책상·러그·방석)와 선반·소품 핫스팟이 방마다 다시 배치됩니다.
  - **심야의 서재**: 앤틱 책장, 초록 뱅커 램프 불빛(깜빡임), 책 더미 위 방석에서 자는 콩이
  - **비 내리는 온실 카페**: 통유리 전체에 빗방울이 흐르고, 라탄 바구니가 콩이의 자리
  - **심야 열차의 침대칸**: 창밖으로 별이 흘러가고, 덜컹임에 맞춰 콩이가 살짝 흔들립니다
  - **눈 내리는 산장**: 창밖에 눈이 내리고 벽난로 불빛이 일렁이며, 양털 담요가 콩이의 자리
- 방마다 콩이의 자리 묘사(자막)가 바뀌고, 폴라로이드·에세이 카드에도 그 방이 찍힙니다. 그림은 `assets/theme_<id>.webp`(1152px) 와 `*_thumb.webp` 입니다.
- **비가 오면** 빗방울은 각 방의 창유리 위에만 흐릅니다. 방마다 창 모양을 픽셀에서 뽑아 낸 마스크(`assets/rainmask_<id>.png`)로 잘라서, 커튼·랜턴·화분 앞으로는 흐르지 않습니다. 콩이의 방은 아침·낮·노을 시간대에 비가 오면 흐린 하늘 버전(`assets/room_<시간대>_rain.webp`)으로 바뀌어 해가 구름에 가려지고 방도 조금 어두워집니다(밤은 `room_bg.webp`). 심야 열차에서는 빗줄기가 달리는 방향으로 비스듬히 흐르고, 산장에서는 비가 오는 동안 눈송이가 멈춥니다.

### 8. 내장 ASMR 믹서 📻
- 방 안의 라디오를 누르면 유튜브로 나가지 않고 바로 재생되는 믹서가 열립니다. 12가지 소리를 볼륨 바로 섞어 "빗소리 50% + 골골송 80% + 장작 30%"처럼 틀어 둘 수 있습니다.
  - 🌧️ 자연의 소리: 창밖 빗소리 · 먼 천둥(빗소리와 함께 틀면 창문이 번쩍) · 잔잔한 파도 · 졸졸 시냇물 · 창밖 바람 · 여름밤 풀벌레
  - 🏠 방 안의 소리: 고양이 골골송(25Hz 저주파) · 타닥타닥 벽난로 · 앤틱 시계 초침 · 연필 사각사각 · 카페 웅성임
  - 🎧 집중 노이즈: 브라운 노이즈
- 추천 조합 7가지(비 오는 밤의 골골송 · 폭풍우 치는 밤 · 고요한 도서관 · 겨울 산장 · 바닷가 카페 · 여름밤 계곡 · 깊은 몰입)와 모두 끄기 버튼이 있습니다. 채널마다 기본 음량을 맞춰서, 같은 %면 비슷한 크기로 들립니다.
- 모든 소리는 Web Audio API로 그 자리에서 합성됩니다(외부 파일·데이터 사용 없음). 상단 `🌧️ 빗소리` 버튼은 믹서의 빗소리 채널과 연결되어 있고, 빗소리가 켜지면 창문에도 비가 흐릅니다. 조합은 기기에 저장되어 다음 방문 때 첫 터치와 함께 다시 켜집니다.

## 🚀 로컬 실행 방법

외부 의존성 없는 정적 웹 앱이므로 로컬 서버로 바로 실행할 수 있습니다:

```bash
# Python 내장 웹 서버 실행
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## ✅ 테스트

Node 20 이상이면 의존성 설치 없이 바로 돌아갑니다.

```bash
npm test
```

- `tests/core.test.js`: XP(체험 0, 분당 1 + 완주 5, 중단 시 절반)·레벨(60/180/420)·포모도로 상태기계(4회마다 긴 휴식, 자동 시작)·스트릭·성장 해금·초 단위 시간 표기
- `tests/i18n.test.js`: ko/en/de 키 수·키 집합 일치, 영어·독일어 문구에 한글 없음, `{변수}` 일치, index.html·app.js 가 쓰는 키 존재
- `tests/shell.test.js`: `sw.js` 캐시 목록에 페이지 파일 누락 없음, 캐시 버전, 외부 스크립트·추적 코드 없음, 공유는 링크(wa.me·intent)만, 푸터의 만든 사람·메일

파일을 고쳤으면 `sw.js` 의 `VERSION` 을 올려야 설치된 앱이 새 파일을 받습니다 (테스트가 최소 버전을 확인합니다).

끝까지 흐름(30초 체험→간식→레벨, 25분→일시정지→이어하기, 자동 포모도로, 핫스팟·믹서, KO/EN/DE, 무릎냥이, 모바일 390×844)은 Playwright 로 자동 확인합니다. 개발용 의존성 하나(playwright)만 필요하고 사이트에는 아무것도 추가되지 않습니다.

```bash
npm i && npx playwright install chromium
python3 -m http.server 8787   # 다른 터미널에서
npm run test:e2e              # 스크린샷은 tests/e2e/shots/ 에 남아요
```

## 🔧 카카오톡 공유 켜기 (선택)

공유 시트의 카카오톡 버튼은 기본으로 휴대폰 공유창이나 "복사 후 붙여넣기"로 동작합니다. 카카오 공유 API로 바로 보내려면:

1. https://developers.kakao.com 에서 앱을 만들고 **플랫폼 → Web** 에 `https://kongi-room.anbu-pilot.workers.dev` 를 등록합니다.
2. 앱 키 중 **JavaScript 키**를 복사해 `app.js` 의 `const KAKAO_JS_KEY=''` 안에 넣습니다.
3. 배포하면 카카오톡 버튼이 카카오 공유창(미리보기 그림 + "나도 해 보기" 버튼)을 엽니다.

## 🌐 도메인 연결 (선택)

도메인을 사면 저장소 **Settings → Pages → Custom domain** 에 입력하고, DNS에 `CNAME anbucare.github.io` 를 추가합니다. 이후 `index.html` 의 canonical·og:url·sitemap.xml 주소를 새 도메인으로 바꾸면 됩니다. GitHub Pages는 예전 `github.io` 주소를 새 도메인으로 자동 301 이동시킵니다.

## 🗺️ robots.txt 참고

프로젝트 사이트라 `robots.txt` 는 `/Kongi-room/robots.txt` 에 있고, 검색엔진이 보는 도메인 루트(`anbucare.github.io/robots.txt`)에는 올라가지 않습니다. 루트에 두려면 `anbucare.github.io` 이름의 저장소를 만들어 그 안에 robots.txt 를 두고 `Sitemap: https://anbucare.github.io/Kongi-room/sitemap.xml` 줄을 적으면 됩니다. 페이지 `<head>` 에는 `<link rel="sitemap">` 으로 사이트맵 위치를 적어 두었습니다.

## 🚀 사이트 배포 (kongi-room.anbu-pilot.workers.dev)

실제 사이트는 Cloudflare Workers + KV 에서 서비스됩니다. GitHub Pages 주소(`anbucare.github.io/Kongi-room`)는 방문자를 이 주소로 넘기는 이동용입니다. main 에 합쳐도 자동으로 올라가지 않으니, 합친 뒤 아래 한 줄을 실행합니다.

처음 한 번만 Cloudflare 에 로그인합니다 (브라우저가 열리고, 토큰은 wrangler 가 알아서 보관합니다):

```bash
npx wrangler login
```

그 뒤에는 main 이 바뀔 때마다 저장소 루트에서:

```bash
node deploy/workers-kv/deploy-wrangler.mjs
```

- `--dry-run` 을 붙이면 올리지 않고 무엇을 올릴지만 보여 줍니다.
- `--prune` 을 붙이면 올린 뒤 직전 버전만 남기고 더 오래된 버전 파일을 KV 에서 지웁니다 (의견·옮기기 코드 데이터는 건드리지 않습니다).
- 끝나면 `https://kongi-room.anbu-pilot.workers.dev/` 를 열어 푸터의 "업데이트 소식"이 바뀌었는지 확인합니다. 설치된 앱은 `sw.js` 의 `VERSION` 이 바뀌면 다음에 열 때 새 파일을 받습니다.

토큰 방식(`deploy/workers-kv/deploy.py`, 로그인을 쓸 수 없는 CI 나 다른 컴퓨터용)도 그대로 있습니다. 환경변수 `CLOUDFLARE_ACCOUNT_ID` 와 `CLOUDFLARE_API_TOKEN`(Workers Scripts: Edit + Workers KV Storage: Edit) 이 필요합니다. 토큰 값은 파일·저장소·대화에 적지 않고, 터미널에 손으로 붙여 넣지도 않습니다(클립보드에서 `pbpaste` 로 바로 환경변수에 넣는 식으로 다룹니다).
