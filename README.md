# 콩이의 방 (Kongi's Room) 🐾

> 일할 때, 공부할 때 내 곁에서 함께 시간을 보내는 아늑한 디지털 반려 메이트 & 집중 타이머

---

## 🌿 프로젝트 개요

'콩이의 방'은 기존의 차갑고 기능적인 생산성 타이머(포레스트, 스터디버니 등)와 달리,  
**혼자 일하거나 공부할 때 찾아오는 적막함을 채워주는 '바디 더블링(Body Doubling)' 반려 공간**입니다.

브라우저 창 한 켠에 아늑한 방을 열어두면, 귀여운 동물(콩이)이 소파 위에서 자기의 시간을 보내며 쌔근쌔근 쉬고 있습니다.  
타이머를 마치면 간식을 줄 수 있고, 가끔은 동물이 나뭇잎이나 털실 뭉치를 물어다 방 선반을 채워줍니다.

---

## ✨ 핵심 컨셉 & 차별점

1. **마지막 2분의 설렘 (기다리는 동물)**
   - 타이머 종료 2분 전이 되면 동물이 잠에서 깨어 기지개를 켜고 빈 밥그릇 앞으로 다가와 화면 쪽을 바라봅니다.
   - 알람 소리의 스트레스 대신 "누군가 나를 기다리고 있는 따뜻한 순간"을 선물합니다.

2. **나만의 시간으로 채워지는 선반 (가변 보상)**
   - 열 번에 한 번쯤 동물이 어딘가에서 나뭇잎, 병뚜껑, 털실 뭉치를 물어옵니다.
   - 게임식 복잡한 화폐나 상점 없이, 오롯이 내가 집중한 시간들이 방의 선반에 자연스럽게 채워집니다.

3. **안전한 벌칙: '빈 밥그릇'**
   - 탭 실수나 일시 정지 때문에 동물이 영영 밖으로 나가버리는 잔인한 벌칙 대신, 문 앞에서 슬쩍 뒤돌아보며 밥그릇이 빈 채로 남습니다. 다음 타이머를 켜면 다시 돌아옵니다.

4. **데스크테리어 & 바디 더블링 (PiP / 작은 창)**
   - 핸드폰은 치워두고, PC 작업 화면 옆에 작은 팝업창이나 탭으로 띄워두는 편안한 Lofi 힐링 공간.
